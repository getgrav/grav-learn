Endpoints for retrieving blueprint schemas used for page templates, user accounts, groups, plugins, themes, configuration and permission definitions, plus `GET /blueprint-files`, which lists files for blueprint folder picker fields. Uploading and deleting files for blueprint `file` fields is covered under [Media](/2/api/endpoints/media): `POST /blueprint-upload` and `DELETE /blueprint-upload`.
