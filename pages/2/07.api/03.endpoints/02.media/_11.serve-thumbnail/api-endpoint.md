---
title: Serve Thumbnail
api:
    method: GET
    path: '/thumbnails/{file}'
    description: 'Serve a cached image thumbnail generated by the API''s thumbnail service. This endpoint is public and needs no authentication. Thumbnail filenames are hashes produced when media is serialized — Admin2 uses the URLs embedded in media responses (`thumbnail_url`, or a user''s `avatar_url`) rather than requesting thumbnails by path. Responses ship with `Cache-Control: public, max-age=31536000, immutable` so they are safe to cache for a year.'
    parameters:
        - name: file
          type: string
          required: true
          description: 'Thumbnail filename (basename only).'
    request_example: ''
    response_example: ''
    response_codes:
        - code: '200'
          description: 'Thumbnail served.'
        - code: '404'
          description: 'Thumbnail not found in cache.'
---

Thumbnails are stored in `cache://api/thumbnails/`. They are generated when an image is serialized in a media response, never by this endpoint, so a thumbnail that is not cached yet (for example after a cache clear) returns 404 until the media listing that contains it is fetched again.
