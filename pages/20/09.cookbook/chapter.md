# Cookbook

This chapter collects practical, problem-and-solution recipes for Grav 2.0 and the Admin2 interface. Each recipe states a problem and walks through a working solution you can adapt.

Recipes here target the current generation of Grav: the REST API, the Admin2 SPA, and the plugin integration events. For recipes that rely on the legacy admin-classic interface, see the [Grav 1.7 Cookbook](/17/cookbook).
